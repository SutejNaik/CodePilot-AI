# Project Description

CodePilot-AI is an AI-powered web application that helps developers review source code.

The application combines traditional static code analysis with AI-generated explanations to detect bugs, security vulnerabilities, code smells, performance issues, and best-practice improvements.

The goal is to provide professional code review reports in seconds.

# Architecture Rules

- Never change the folder structure.
- Never rename folders.
- Never modify unrelated files.
- Keep code modular.
- Routes should only call services.
- Business logic belongs inside services.
- Use reusable React components.
- Keep files small.
- Return JSON from every API.
- Follow clean coding practices.

# Development Workflow

1. Build one feature at a time.

3. Test it.
4. Commit to Git.
5. Move to the next feature.
